# 🎮 Game Design Document

## 1. Roles
|     Role    |   Description  |
|-------------|----------------|
|   Werewolf  |  Kill at night |
|   Villager  |    Vote ban    |
|    Seer     |   Check role   |
|    Guard    | Protect player |
...

## 2. Game Phases
### Night
- Werewolf chọn target
- Seer check
- Guard protect

### Day
- Public discussion
- Vote eliminate

## 3. Win Conditions
- Werewolf thắng khi số sói >= dân
- Dân thắng khi giết hết sói

## 4. Edge Cases
- Player disconnect
- Tie vote
- Multiple kills

## 5. Rules
- 1 vote / player
- Dead player không được vote
